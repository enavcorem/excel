## לבדוק באקסל בעברית
- `TEXT(A2,"mmmm")` ← "ינואר", `"dddd"` ← "יום ראשון": נבדק בצילום (7.11).
- יישור: **בגיליון עברי מספר ותאריך נצמדים לימין**, וטקסט שנראה כמו תאריך לשמאל (נבדק בצילום, 7.11).
