## לבדוק באקסל בעברית (השמות בלומדה נכתבו מהידע, לא מצילום)

- "קבץ..." ושם החלון "קיבוץ"; נוסח ההודעה כשאי אפשר לקבץ.
- "שדה בסיס" ו"פריט בסיס" בחלון של % הפרש מ..., והפריט "(הקודם)".
- "הגדרות שדה ערכים..." ← "שם מותאם אישית". הכותרת של שדה שנגרר פעמיים: "סכום של הכנסות2".
- הכרטיסייה "ניתוח PivotTable", הכפתורים "הוסף כלי פריסה" ו"הוסף ציר זמן", ו"שדות, פריטים וערכות ← שדה מחושב...".
- תוויות הקיבוץ: חודשים "ינו, פבר..." (מופיע בצילום), רבעונים "רבע1" (צמוד, נבדק באקסל 1.11).
- `TEXT(A2,"mmmm")` מחזירה "מרץ", ו-`"dddd"` מחזירה "יום שישי" (קודי התבנית באנגלית גם באקסל בעברית).
